# Свой сервер для Telegram (VLESS Reality) и личные ключи

Telegram у многих провайдеров заблокирован **по IP-адресам**, поэтому обход DPI ему не помогает: соединение с серверами Telegram просто не устанавливается. Помогает только свой сервер за границей, через который пойдёт трафик Telegram (и только он).

Эта инструкция поднимает такой сервер за ~10 минут:

- протокол **VLESS + Reality**: снаружи сервер выглядит как обычный сайт (например, www.microsoft.com), поэтому его сложно обнаружить и заблокировать;
- сервер пропускает **только Telegram**: даже если ключ утечёт, через него нельзя открыть другие сайты;
- у каждого друга **свой ключ**, его можно отозвать одной командой;
- ключ выдаётся **файлом доступа** `.bdpi` или кодом: друг импортирует его в ByeDPI PC в один клик, и Telegram сразу идёт через сервер.

## 1. Сервер

Подойдёт самый дешёвый VPS (1 ядро, 512 МБ) **за пределами России**, например в Нидерландах, Финляндии или Германии, с Debian 12 или Ubuntu 22.04/24.04. После покупки у вас будут IP-адрес и пароль root.

Подключитесь по SSH: на Windows откройте «Терминал» или PowerShell и выполните `ssh root@IP_СЕРВЕРА`.

## 2. Установка (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/anomal3/ByeDPI-PC/main/docs/server/install.sh | bash
```

Скрипт:

1. ставит [sing-box](https://sing-box.sagernet.org) из официального репозитория;
2. генерирует ключи Reality;
3. пишет конфиг `/etc/sing-box/config.json`: VLESS Reality на порту 443, разрешены только домены и подсети Telegram;
4. запускает службу и создаёт первого пользователя.

В конце вы увидите ссылку `vless://…`, **код** `bdpi:…` и путь к файлу `/root/telegram-ИМЯ.bdpi`.

Порт и сайт для маскировки можно задать явно: `bash install.sh 8443 www.apple.com`.

## 3. Ключи для друзей

```bash
telegram-add-user Ivan            # новый личный ключ: ссылка, код и файл /root/telegram-Ivan.bdpi
telegram-add-user --list          # кто подключён
telegram-add-user --remove Ivan   # отозвать ключ
```

Отправьте другу **код** (это одна строка, её удобно переслать в мессенджере) или **файл** `.bdpi`. Скачать файл с сервера можно так: `scp root@IP_СЕРВЕРА:/root/telegram-Ivan.bdpi .`

## 4. Как друг подключается

1. Устанавливает ByeDPI PC ([Releases](https://github.com/anomal3/ByeDPI-PC/releases)).
2. **Настройки → Обмен настройками → Импорт → Вставить код**. Или просто перетаскивает файл `.bdpi` в окно программы.
3. Нажимает «Применить» и большую кнопку подключения.

После импорта внешний прокси включится сам, а у правила «Telegram» появится маршрут «Внешний прокси». Остальные сайты продолжат работать через обход DPI или напрямую.

> Для режима «Внешний прокси» программе нужен sing-box. Он уже лежит в сборке, а права администратора понадобятся один раз за сеанс (или ни разу, если включён автозапуск).

## Если у сервера открыт только порт SSH (NAT-VPS)

У недорогих NAT-VPS наружу пробрасывается только порт SSH (например, `41830 → 22`), и VLESS на 443 из интернета недоступен. Тогда туннелем служит сам SSH: ByeDPI PC понимает ключи `ssh://` и через sing-box ходит в интернет через ваш сервер.

```bash
# 1 раз: внешний адрес и порт, по которым вы подключаетесь к серверу по SSH
bash ssh-tunnel.sh 203.0.113.5 41830          # скрипт: docs/server/ssh-tunnel.sh

tunnel-add-user Ivan            # доступ только к Telegram (для друзей)
tunnel-add-user Me --full       # полный доступ (все правила с маршрутом «Внешний прокси»)
tunnel-add-user --list
tunnel-add-user --remove Ivan
```

Каждая учётка получает только проброс соединений: ни shell, ни входа в систему. Для друзей файрвол сервера пропускает только адреса Telegram. Команда печатает ключ `ssh://…`, код `bdpi:…` и сохраняет файл доступа `/root/tun-ИМЯ.bdpi`; импорт в программу такой же, как для VLESS.

Учтите, что SSH-туннель передаёт только TCP: сообщения, фото и каналы Telegram работают, а голосовые звонки (UDP) могут не соединяться.

## Поделиться своими настройками

Поделиться можно не только ключом. **Настройки → Обмен настройками → Поделиться**: выберите, что отправить (стратегию, правила, ключ внешнего прокси), и сохраните файл или скопируйте код. Например, подобранную под вашего провайдера стратегию можно отправить соседу с тем же провайдером, и ему не придётся ждать подбора.

## Безопасность

- Ключ **личный**: все, у кого он есть, пользуются вашим сервером. Выдавайте каждому свой ключ и отзывайте ненужные.
- Сервер не хранит историю и пропускает только Telegram, остальные соединения отклоняются.
- Переписка в Telegram остаётся зашифрованной самим Telegram: владелец сервера не видит её содержимого.

## Если что-то не работает

- `systemctl status sing-box` — служба должна быть `active (running)`.
- `journalctl -u sing-box -e` — журнал сервера.
- Проверьте, что в панели хостинга открыт порт 443/TCP.
- Если провайдер начал блокировать сам сервер, поменяйте сайт маскировки: `nano /etc/sing-box/byedpi-telegram.env` и `config.json` (поля `server_name` и `handshake.server`), затем выполните `systemctl restart sing-box` и выдайте ключи заново.
